# Code of Conduct

## Our Standards

This project is intended to be an open enviroment where people can collaborate,
exchange ideas, and work towards common goals.

Everyone participating in this project is expected to:

- Treat others with respect
- Be open to different ideas and perspectives
- Providde constructive criticism
- Avoid harassment, discrimination, and personal attacks
- Focus discussions on the project rather than personal disagreements
- Help maintain a welcoming enviroment for new contributors

## Unacceptable Behavior

Harassment, threats, intimidation, discrimination, and disruption of project discussions will not be tolerated.

## Enforcement

Project maintainers are responsible for addressing violations of this code of conduct.
They may remove inappropriate contect, issue warnings, or restrict participation when necessary.

## Scope

This code applies to all project spaces, including GiutHub issues, pull requests, discussions, and other communication channels.
